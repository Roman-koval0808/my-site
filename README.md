# NetSwagger Elegant Next.js Redesign

A one-page Next.js redesign inspired by the structure and content of https://www.netswagger.org/ while using a more energetic, premium visual direction.

## Included

- NetSwagger wordmark treatment in header and footer
- Hero using the original NetSwagger hero photography
- Services with icons and links to the original NetSwagger service pages
- Recognition / review assets from the reference site
- All eight featured portfolio items from the reference homepage
- Testimonials
- Five-step delivery process
- Helpful-information section
- Free-consultation CTA and contact details
- Fully responsive layout

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Customize

Main content is in `app/page.tsx` and design tokens/styles are in `app/globals.css`.
